# 日序 Dayflow

> 本地优先的桌面日程中枢：把学期、项目、课程和每天的重点，收进一摞会呼吸的卡片里。

日序是一款面向学生与研究者的 Windows 桌面日程应用。它不依赖云端账户，所有日程默认只保存在本机；打开就能用，关掉后也不会把数据传到任何服务器。

## 下载与运行

- 下载 `Dayflow-1.0.0-portable.exe`
- 双击即可打开，无需安装、无需 Node.js、无需配置环境
- 支持 Windows 10 / 11 x64
- 首次启动会在 `%APPDATA%\Dayflow` 创建独立数据目录；程序本身不写入安装目录
- 想彻底卸载：退出应用后删除 `%APPDATA%\Dayflow` 即可

> 便携版每次运行会先解包到临时目录，首次启动可能比后续启动稍慢。

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 今日 | 大日期、今日重点卡片堆、完成环、每日习惯、接下来、近期截止 |
| 安排 | 今天 / 明天 / 后天 / 之后四张日卡，一次只看一天的卡片清单 |
| 总览 | 18 周学期地图、领域分布、未来 8 周热力、长期主线 |
| 排期 | 4 / 6 / 8 周视图，按教学周分组 |
| 甘特 | 拖动改期、拖边改时长、双击空白新建，支持领域筛选与重点标记 |
| 日历 | 月历与当天详情 |
| 规划 | 长期主线进度与课程进度 |
| 登记 | 对话、语音、文件导入、传统表单四种录入方式 |
| 设置 | 启动、外观、接口、数据、本机信息 |

### 录入方式

- **对话**：像和秘书说话一样登记日程，例如「明天下午三点提交月工作总结」
- **语音**：点麦克风说话，优先使用系统语音识别；失败时回退 Windows 本地识别
- **导入**：支持 `.ics` / `.json` / `.txt`，先预览、自动去重，再导入
- **传统表单**：顶栏「表单」或对话底部「用表单填写」，填写事项、日期、时间、类别、优先级、备注

### 按时间紧迫度排序

- 安排、今日重点、日历、排期、甘特统一按日程时间排序
- 顺序：逾期优先 → 同一天按时间（早的在前）→ 同一时间再按优先级
- 无具体时间的全天事项排在当天定时事项之后
- 已完成事项排在后面，不会打断当前待办

### 正向反馈

- 完成事项时：纸屑、绿色勾选徽章、浮起的 `+1`、完成环脉冲
- 会按场景给出不同的暖心文案，例如「恭喜又完成一项，辛苦啦 🌹」「重点事项拿下，辛苦啦 🌹」「只剩最后一项了，收个漂亮的尾吧 ✨」
- 今日全部收尾会出现「今天稳稳收住了」大卡，并提醒给自己一点休息时间
- 连续完成会累计；完成记录进入今日完成环、连续天数与本周完成率
- 文案原则：具体、即时、不制造愧疚，不用催促语气，不把休息当成失败

### 快速修改与删除

- 鼠标移到任意日程卡片，右侧出现「修改 / 删除」
- 修改打开完整编辑抽屉
- 删除带 5 秒撤销，误删可恢复
- 触屏设备上按钮常显

### 重点 / 其他自如切换

- 今日安排顶部是「重点 / 其他」分段开关，一键切换内容
- 两侧显示实时数量，不再限制重点 3 条、其他 4 条
- 点星标或拖到另一个标签，会自动切到目标内容
- 切换到重点时展示重点卡片，切换到其他时展示全部其他任务
- 切换使用发牌动画，保留列表滚动位置

### 标为重点

- 日程卡片右侧的星标按钮，一键标为重点 / 取消重点
- 任务卡上的「重点」徽章、编辑抽屉里的「标为重点」开关也可操作
- 标为重点后自动进入今日重点卡片堆，取消后回到普通列表
- 切换时使用 FLIP 位移动画，并带金色脉冲反馈

### 直接拖动排序

- 大部分卡片可直接按住卡片本身拖动，不需要先找握把
- 日程卡片拖到另一张卡片上即可改变顺序，不需要拖到指定区域
- 拖动后进入「手动排序」，顺序保存在本机；「安排」页点「按时间」可恢复紧迫度排序
- 日历事件、排期小卡、甘特条仍可直接拖动改期
- 拖到日卡、日历格、排期格可改日期；没落到目标上会弹回
- 拖动浮层只改变 transform，不触发列表重排；低配模式自动关闭倾斜与回弹

### 拖动归类

- 拖动日程卡片到底部「拖动归类」栏，可直接改重要程度和领域分区
- 重要程度：重点 / 普通 / 轻
- 分区：科研 / 学工 / 课业 / 长期
- 也可以直接拖到「今日重点」「其他安排」标题或顶部的领域筛选按钮
- 改完有撤销；删除、改期、归类都走同一条数据保存与回滚链路

### 数据一致性

- 日程、排序、主线、课程、归类与重点修改都会先写入本机，再给成功反馈
- 删除日程时同步清理手动排序中的残留 ID
- 删除主线/课程时同步解除日程关联，并清理对应排序
- 设置类写入按顺序执行，避免连续拖动造成顺序丢失
- 数据文件使用临时文件 + 原子替换，异常中断不会留下半截 JSON

### 规划卡片管理

- 日历事件、排期小卡、甘特条悬停都有一键「修改 / 删除」
- 规划页的主线卡片、课程行可直接拖动卡片调整顺序，顺序会保存在本机设置里
- 主线、课程都有编辑与删除；删除时关联日程保留，只解除关联
- 卡片排序使用 FLIP 过渡，删除前有确认提示

### 自动适配

首次启动会根据当前电脑自动选择更合适的显示方案：

- 屏幕工作区：调整窗口尺寸与最小尺寸，小屏自动进入紧凑布局
- 刷新率、内存、显卡：高配全效果；低配自动降低阴影、模糊与粒子数量
- 设置 → 外观 → **自动适配** 可手动关闭
- 卡片动画、发牌转场、完成特效在所有档位都保留

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `N` | 新建日程（对话窗口） |
| `Ctrl Shift M` | 打开模块九宫格 |
| `Ctrl Tab` / `Ctrl Shift Tab` | 下一个 / 上一个模块 |
| `Ctrl PageDown` / `Ctrl PageUp` | 下一个 / 上一个模块 |
| `Alt ←` / `Alt →` | 上一个 / 下一个模块 |
| `1`–`9` | 今日 / 安排 / 总览 / 排期 / 甘特 / 日历 / 规划 / 登记 / 设置 |
| `Ctrl K` | 命令面板 |
| `Ctrl Enter` | 抽屉内保存 |
| `Esc` | 关闭面板、抽屉或对话窗口 |

触控板左右滑、鼠标侧键也可以切换模块。

## 数据与隐私

- 日程、设置、日志都保存在本机 `%APPDATA%\Dayflow`
- 不登录、不上传、不包含第三方统计
- 应用内置的本机 HTTP API 只监听 `127.0.0.1`，需要 token
- 可选接入自己的大模型 Key（设置 → 接口 → 模型解析）；不填写时完全使用本地规则解析
- 仓库与安装包不包含任何个人日程数据；首次启动只有几条可删除的示例

## 从源码运行

需要 Node.js 20+ 与 npm。

```bash
git clone https://github.com/Samuel12312541235/TIP.git
cd TIP
npm install
npm start
```

## 打包 Windows 便携版

```bash
npm install
npm run dist
```

产物在 `release/Dayflow-1.0.0-portable.exe`。

## 技术栈

- Electron 45
- 原生 HTML / CSS / JavaScript，无前端框架、无构建步骤
- 本机 HTTP API + JSON 文件存储
- Web Animations API + CSS 卡片堆叠
- 可选 OpenAI-compatible Chat Completions（DeepSeek JSON 模式）

## 目录

```
main.js                  Electron 主进程、窗口、托盘、提醒、自动适配
preload.js               安全 IPC 桥
renderer/                界面、视图、动画、卡片系统
server/                  本地 HTTP API、存储、规则解析、初始数据
agent/                   本机 Agent CLI 与接入说明
scripts/listen.ps1       Windows 语音识别回退
assets/                  图标
```
